# Baby Keyboard Explorer · 小小探索家

[![在线体验](https://img.shields.io/badge/Play-Online-5b8def)](https://baby-games-vault.github.io/baby-keyboard-explorer/)
[![纯静态项目](https://img.shields.io/badge/Runtime-Static%20HTML%2FCSS%2FJS-38a169)](https://github.com/baby-games-vault/baby-keyboard-explorer)

> 一个为约 1 岁宝宝设计的低刺激键盘与鼠标探索小游戏。

## 在线体验

打开：<https://baby-games-vault.github.io/baby-keyboard-explorer/>

在线版本适合快速体验和分享；如果要给宝宝使用，建议下载仓库文件后在本机以浏览器应用模式运行。

## 项目简介

宝宝不需要认识字母、理解规则或完成任务，只要自然地按键、移动鼠标、点击鼠标，就能看到温和、缓慢、可预测的视觉反馈。

这个项目把宝宝对家长电脑的好奇心，转化为一个短时、独立、可控的探索空间。它不是益智竞赛产品，也不替代家长陪伴或专业的视力、发育建议。

## 项目价值

- **鼓励因果探索**：宝宝可以直观看到“我按了键/动了鼠标 → 屏幕发生变化”。
- **降低误操作风险**：不读取、修改或上传电脑文件，不提供外部链接，并拦截页面内常见的返回、刷新和关闭操作。
- **程序化控制时长**：单次游戏最多 5 分钟，到时自动进入锁定结束页。
- **优先考虑低刺激**：大元素、低饱和配色、慢速淡入淡出、默认静音和分段休息。
- **适合持续扩展**：这是 `baby-games-vault` 组织中的第一个游戏，后续可以沿用相同安全约定添加更多小游戏。

## 游戏逻辑

```text
开始页
  ↓ 家长点击开始
全屏探索（最多 5 分钟）
  ↔ 每约 60 秒进入一次 5–8 秒休息提示
  ↓ 达到 300 秒
锁定结束页
  ↓ 家长完成两次组合键长按并点击确认
返回开始页并退出全屏
```

### 互动反馈

| 宝宝动作 | 屏幕反馈 |
| --- | --- |
| 按普通键盘按键 | 随机出现柔和色块或简单表情图形 |
| 移动鼠标 | 在指针位置出现缓慢扩散的光圈 |
| 点击鼠标 | 在点击位置出现气泡 |
| 连续快速操作 | 最多保留 4 个动画元素，避免画面堆积 |

游戏不设置积分、失败、倒计时数字或必须完成的任务，以减少挫败感和持续注视压力。

### 时间与护眼逻辑

- 总时长硬上限为 **300 秒**，休息时间包含在这 5 分钟内，不会延长游戏。
- 约在第 60、120、180、240 秒出现休息画面，提示“看看远处，眨眨眼”。
- 页面隐藏、切换窗口或电脑短暂睡眠后，恢复时仍按实际经过时间计算，保证不会超过 5 分钟。
- 支持系统的 `prefers-reduced-motion` 设置；开启后会尽量减少动态效果。
- 默认静音；声音只在家长开始页主动勾选后启用，且音量很低。

## 快速开始

### 本地直接运行

1. 下载或克隆本仓库。
2. 用 Chrome 或 Edge 打开 `index.html`。
3. 由家长点击“家长开始游戏”。
4. 浏览器会尝试进入全屏，宝宝即可开始探索。

项目不依赖 npm、框架、后端或外部资源，直接打开 HTML 即可运行。

### 推荐：浏览器应用模式

应用模式会使用独立窗口运行，宝宝不容易看到普通标签页、地址栏或其他网页。

Edge 示例（将路径替换为本机实际路径）：

```text
msedge.exe --app="file:///C:/path/to/baby-keyboard-game/index.html"
```

Chrome 示例：

```text
chrome.exe --app="file:///C:/path/to/baby-keyboard-game/index.html"
```

## 家长退出方式

页面右下角始终以小字体显示退出规则，防止家长忘记：

1. 同时按住 `Ctrl + Alt + Shift`，再按住 `Q` 2 秒；
2. 松开全部按键；
3. 在 5 秒内再次按住同样的组合键 2 秒；
4. 点击出现的“结束游戏并退出全屏”按钮。

普通按键、鼠标点击和不完整的组合键都不会退出游戏。`Esc` 是浏览器保留的全屏快捷键，可能使浏览器离开全屏，但不会结束游戏、重置计时或跳转到结束页。

## 隐私与安全边界

- 不联网，不调用 `fetch`、XHR 或 WebSocket。
- 不读取、写入、删除或上传电脑文件。
- 不使用摄像头、麦克风、剪贴板和下载功能。
- 不保存宝宝的按键、鼠标轨迹或游戏内容。
- 网页无法屏蔽操作系统级快捷键（例如 `Alt+Tab`），因此仍建议家长陪同，并优先使用浏览器应用模式。
