# 小小探索家 · Baby Keyboard Explorer

一个面向约 1 岁宝宝的离线键盘与鼠标探索小游戏。宝宝不需要认识字母、理解规则或完成任务，只要自然地按键、移动鼠标、点击鼠标，就能看到温和、缓慢、可预测的视觉反馈。

> 项目定位：亲子陪伴和感官探索工具，不是益智竞赛产品，也不能替代家长陪伴或专业的视力、发育建议。

## 为什么做这个项目

宝宝通常会对家长正在使用的电脑产生兴趣。与其让宝宝随机操作工作窗口，不如提供一个专门隔离的探索空间，让这份好奇心变成安全、短时、可控的亲子互动。

这个项目的价值包括：

- **把好奇心变成探索**：按键和鼠标动作都会得到即时反馈，宝宝可以观察“我做了什么、屏幕发生了什么”。
- **减少误操作风险**：游戏不读取或修改电脑文件、不联网、不提供外部链接，并拦截页面内常见的返回、刷新和关闭操作。
- **把时长控制交给程序**：单次游戏最多 5 分钟，到时进入锁定结束页，避免因为家长分心而无限使用。
- **优先考虑低刺激**：使用大元素、低饱和颜色、慢速淡入淡出、默认静音和分段休息提示。
- **方便持续扩展**：这是 `baby-games-vault` 组织中的第一个游戏，后续可以继续添加颜色、形状、动物等独立小游戏。

## 游戏逻辑

游戏采用单向状态流程：

```text
开始页
  ↓ 家长点击开始
全屏探索（最多 5 分钟）
  ↔ 每约 60 秒进入一次 5–8 秒休息提示
  ↓ 达到 300 秒
锁定结束页
  ↓ 家长完成两次组合键长按并点击确认
返回开始页并退出全屏
```

### 互动反馈

| 宝宝动作 | 屏幕反馈 |
| --- | --- |
| 按普通键盘按键 | 随机出现柔和色块或简单表情图形 |
| 移动鼠标 | 在指针位置出现缓慢扩散的光圈 |
| 点击鼠标 | 在点击位置出现气泡 |
| 连续快速操作 | 最多保留 4 个动画元素，避免画面堆积 |

游戏不设置积分、失败、倒计时数字或必须完成的任务，降低挫败感和持续注视压力。

### 时间与护眼逻辑

- 总时长硬上限为 **300 秒**，休息时间包含在这 5 分钟内，不会延长游戏。
- 约在第 60、120、180、240 秒出现休息画面，提示“看看远处，眨眨眼”。
- 页面隐藏、切换窗口或电脑短暂睡眠后，恢复时仍按实际经过时间计算，保证不会超过 5 分钟。
- 支持系统的 `prefers-reduced-motion` 设置；开启后会尽量减少动态效果。
- 默认静音；声音只在家长开始页主动勾选后启用，且音量很低。

## 如何使用

### 最简单的方式

1. 用 Chrome 或 Edge 打开本目录中的 `index.html`。
2. 由家长点击“家长开始游戏”。
3. 浏览器会尝试进入全屏，宝宝即可开始探索。
4. 5 分钟结束后，页面会自动进入“今天的探索完成啦”锁定页。

### 更安全的方式：浏览器应用模式

建议为 `index.html` 创建一个 Chrome/Edge 应用模式快捷方式。这样游戏在独立窗口中运行，宝宝不容易看到普通标签页、地址栏或其他网页。

Edge 示例（请把路径替换为本机实际路径）：

```text
msedge.exe --app="file:///C:/path/to/baby-keyboard-game/index.html"
```

Chrome 示例：

```text
chrome.exe --app="file:///C:/path/to/baby-keyboard-game/index.html"
```

### 家长退出方式

页面右下角始终以小字体显示退出规则，防止家长忘记：

1. 同时按住 `Ctrl + Alt + Shift`，再按住 `Q` 2 秒；
2. 松开全部按键；
3. 在 5 秒内再次按住同样的组合键 2 秒；
4. 点击出现的“结束游戏并退出全屏”按钮。

普通按键、鼠标点击和不完整的组合键都不会退出游戏。`Esc` 是浏览器保留的全屏快捷键，可能使浏览器离开全屏，但不会结束游戏、重置计时或跳转到结束页；使用应用模式可以避免浏览器界面暴露给宝宝。

## 文件说明

```text
index.html   页面结构、开始页、游戏页、休息页和锁定结束页
styles.css   低刺激配色、布局、动画和减少动态效果适配
game.js      游戏状态机、计时器、输入处理、声音和家长退出逻辑
```

项目不依赖 npm、框架、后端或外部资源，直接打开 HTML 即可运行。

## 隐私与安全边界

- 不联网，不调用 `fetch`、XHR 或 WebSocket。
- 不读取、写入、删除或上传电脑文件。
- 不使用摄像头、麦克风、剪贴板和下载功能。
- 不保存宝宝的按键、鼠标轨迹或游戏内容。
- 网页无法屏蔽操作系统级快捷键（例如 `Alt+Tab`），因此仍建议家长陪同，并优先使用浏览器应用模式。

## 后续扩展方向

后续游戏可以沿用相同的安全约定：独立仓库、默认静音、单次时长上限、分段休息、家长退出组合键，以及不访问用户文件。这样整个 `baby-games-vault` 可以逐步形成一个风格统一、边界清晰的宝宝小游戏集合。
